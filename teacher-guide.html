TEACHER GUIDE · 45분 수업

내가 가르친 AI, 친구 손도 알아볼까?

머신러닝의 이해 — 지도학습 / 핸드포즈로 마퀸 조작하기

수업 목표

  • 손 모양이 입력 데이터, ‘앞으로·정지’ 등의 이름이 정답(레이블)임을 설명한다.
  • 학습과 테스트의 역할을 구분한다.
  • 데이터의 양·다양성·균형·정답의 정확성을 살펴보고, 오답을 줄일 방법을 제안한다.

준비와 역할

2~3명씩 모둠을 구성한다. 카메라가 있는 컴퓨터와 인터넷을 준비한다. 로봇 활동에는 Web Bluetooth를 지원하는 브라우저, micro:bit, 마퀸, MakeCode 프로그램이 필요하다. 장비가 없어도 학습·테스트 활동은 가능하다.

손을 보여주는 사람, 버튼을 누르고 실제 정답을 기록하는 사람, 결과를 관찰하는 사람으로 역할을 나누고 교대한다. 수업 전 카메라·연결·정지 동작을 확인한다. 새로고침하면 데이터가 사라지므로 결과는 활동지에 기록한다.

핵심 개념을 쉽게 설명하기

개념학생에게 할 말
지도학습“예시와 정답을 함께 알려주고, 새 예시의 정답을 예상하게 하는 거예요.”
데이터 수집“이 손 모양은 ‘앞으로’라고 이름을 붙여 예시를 모아요.”
학습“학습하기를 눌러 모아둔 예시를 이번 모델에 적용해요.”
테스트“배울 때 쓰지 않은 새로운 손으로 얼마나 잘 맞히는지 확인해요. 여기서 시험한 손은 학습 데이터에 들어가지 않아요.”
정답률“맞힌 시험 수 ÷ 전체 시험 수 × 100이에요. 10번 중 7번 맞히면 70%예요.”
일반화“외웠던 예시뿐 아니라 친구의 손이나 다른 각도도 알아보는 거예요.”

45분 수업 흐름

시간활동질문·확인할 점
0~5분탐구 질문 제시, 입력과 정답 소개“사람마다 손이 다른데 AI도 알아볼까요?”
5~13분다섯 동작의 손 모양 정하기 → 각 동작 30개 이상 수집 → 학습하기서로 구분되는 손 모양과 일관된 정답 이름을 사용한다. 수집 개수와 학습 버튼을 누른 횟수는 다르다.
13~21분친구의 손으로 동작별 5회씩 시험하고 결과 기록시험 전에 실제 정답을 선택한다. AI의 예상을 보고 정답을 바꾸지 않는다. 손을 내렸다가 다시 보여주며 시험한다.
21~31분오답 안내 살펴보기 → 가설 세우기 → 새 예시 추가 → 재학습“어떤 동작이 헷갈렸나요? 무엇을 바꾸면 좋아질까요?” 수집 방법 등 바꿀 조건을 하나 정한다.
31~39분새 모델을 동작별 5회씩 다시 시험 → 마퀸 조작같은 사람·동작별 횟수·환경에서 새롭게 손을 보여주며 비교한다. 테스트 조건을 적고, 한 번의 개선으로 원인이 증명되었다고 단정하지 않는다.
39~45분모둠별 결과 공유, 정리 질문“어떤 데이터를 바꿨고 어떤 결과가 나왔나요? 다음에는 무엇을 확인할까요?”

‘왜 안 될까?’를 설명하는 방법

  • 예시가 적음: “모델이 참고할 예시가 적어요. 다양한 손 모양을 더 보여주면 도움이 될 수 있어요.” 개수가 늘었다고 항상 좋아지는 것은 아니다.
  • 한 동작에 데이터가 몰림: “특정 동작의 예시가 너무 많아요. 적은 동작도 더 모아 비교해봅시다.” 앱은 최대 개수가 최소의 3배 이상이거나 빠진 동작이 있으면 안내한다.
  • 같은 오답이 반복됨: “실제 ‘앞으로’를 ‘정지’로 여러 번 예상했네요. 손 모양이 비슷한지, 정답을 잘못 붙였는지, 다른 각도의 예시가 부족한지 확인해봅시다.” 앱은 같은 오답 쌍이 2회 이상이면 해당 기록을 보여준다. 원인을 확정하지 않는다.
  • 시험 횟수가 적음: “잘 배웠는지 판단할 근거가 적어요.” 시험이 적다는 이유로 모델이 나빠지는 것은 아니다.
  • 정답률이 그대로이거나 낮아짐: 실패가 아니라 탐구 결과다. 추가한 예시의 정답과 다양성, 시험 조건이 달라졌는지 확인하고 다음 실험을 제안한다.

마지막 확인 질문

  1. 이 활동에서 입력 데이터와 정답은 각각 무엇인가요?
  2. 테스트를 100번 하면 모델이 자동으로 더 잘 맞히게 될까요? 왜 그럴까요?
  3. 같은 손 모양 100개와 여러 각도의 손 모양 20개 중 무엇이 나을까요? 개수만으로 결정할 수 있을까요?
  4. 학습 버튼을 여러 번 누르는 것과 학습 데이터를 바꾸는 것은 어떻게 다른가요?
  5. 오답을 줄이기 위해 무엇을 바꾸었고, 어떤 기록이 근거가 되나요?

교사용 유의점

이 앱의 KNN은 예시를 저장해 비슷한 이웃들의 정답으로 분류한다. 학습 버튼을 누른 횟수는 신경망의 에포크가 아니다. 동일한 데이터로 다시 학습해도 같은 입력에 대한 예측은 달라지지 않는다. 데이터 수를 이유로 의도적인 오작동이나 무작위 오답을 만들지 않는다.

동작별 최소 30개로 학습하고 각 동작을 5회 이상, 최소 총 25회 시험한다. 모든 동작의 정답률이 80%를 초과해야 마퀸 조작이 열린다. 5번 중 4번 정답은 정확히 80%이므로 통과하지 못한다. 현재 모델의 동작별 누적 시험 기록으로 계산하며 재학습하면 다시 시험한다. 이는 수업 활동의 통과 조건이며 새로운 상황에서 성능을 보장하는 과학적 경계는 아니다.

앱의 ‘비슷한 샘플의 일치 비율’은 이웃의 투표 비율이며 시험 정답률이나 정답일 확률이 아니다. 테스트 결과를 보고 모델을 개선한 뒤에는 새 손 데이터로 다시 시험한다. 엄밀한 최종 평가가 필요하면 개선 과정에서 참고하지 않은 별도의 사람·데이터를 마지막에 사용한다.

로봇은 낮은 속도와 충분한 공간에서 시험한다. 정지 버튼 위치를 먼저 알려주고, 연결이 끊기면 로봇 상태를 직접 확인한다.

오늘의 정리: AI는 우리가 준 예시와 정답을 바탕으로 판단한다. 테스트로 부족한 점을 발견하고, 데이터를 개선해 다시 확인한다.
