# 머신러닝의 이해 · 학습과 테스트

덕소중학교 핸드포즈 마퀸 수업용 실험 버전. 기존 ai-handpose-recognition과 독립된 저장소입니다.

1. **수집·학습**: 다섯 동작에 정답을 붙여 각각 30개 이상 수집합니다. 길게 누르면 연속 수집, 키보드로 버튼을 실행하면 한 개를 수집합니다. ‘모델 학습하기’를 눌러야 현재 데이터를 모델에 적용합니다.
2. **테스트**: 실제 정답을 선택한 뒤 새로운 손으로 한 번씩 시험합니다. 시험 데이터는 학습 데이터에 추가하지 않습니다. 실제 정답과 AI 예상을 비교한 정답률과 모델별 기록을 보여줍니다.
3. **개선**: 학습 단계로 돌아가 데이터를 추가·삭제하고 다시 학습합니다. 새 모델의 정답률은 새로 집계하며 이전 모델 기록은 남습니다.
4. **마퀸 조작**: 현재 모델에서 다섯 동작을 각각 5회 이상(최소 총 25회) 시험하고 모든 동작의 정답률이 80%를 초과한 후 연결·시작합니다. 연결만으로 움직이지 않습니다. 손 미검출 시 정지 명령을 보내되 조작 모드는 유지하고, 손이 다시 보이면 자동으로 이어갑니다. 단계 전환·창 전환 시 조작을 중지하며 연결은 유지합니다.

KNN은 가중치를 반복 훈련하는 모델이 아닙니다. 학습 버튼은 수집 데이터의 복사본을 분류 모델로 확정합니다. 이웃 일치 비율은 정답률과 다르며 정답률은 기록한 시험 결과로 계산합니다.

## 실행

```sh
make preview
# http://localhost:8016
make test
```

카메라에는 localhost 또는 HTTPS가 필요합니다. 카메라 영상과 샘플은 서버에 업로드하지 않으며 메모리에만 저장됩니다. 새로고침하면 초기화됩니다. MediaPipe 라이브러리와 손 인식 모델은 외부 CDN에서 받으므로 인터넷 연결이 필요합니다.

블루투스는 Web Bluetooth를 지원하는 브라우저와 실제 micro:bit/Maqueen이 필요합니다. [MakeCode 설치 안내](MICROBIT_MAKECODE.md)를 참고하세요. 통신 단절 시 앱에서 정지 신호 전달을 보장할 수 없으므로 로봇 펌웨어에도 수신 중단 시 정지 처리를 권장합니다.

## 시험 조건과 피드백

- 실제 정답으로 선택한 동작별로 횟수를 집계합니다. 한 동작만 10번 시험해도 조작은 열리지 않습니다.
- 각 동작 5회 이상 시험하고 모든 동작의 정답률이 80%를 초과해야 조작할 수 있습니다. 정확히 80%는 통과하지 못합니다. 정답률은 현재 모델의 동작별 누적 기록으로 계산합니다. 다시 학습하면 새 모델에서 다시 시험해야 합니다.
- 수집 데이터가 바뀌면 재학습 전에는 테스트와 조작을 할 수 없습니다.
- ‘왜 잘 안 될까요?’는 예시 부족(동작별 30개 미만), 불균형(최대/최소 3배 이상 또는 빠진 동작), 반복 오답(같은 쌍 2회 이상), 시험 부족을 안내합니다. 수업용 기준이지 성능 보장 기준이 아닙니다.
- 안내는 가능한 원인과 개선 방법이며, 횟수를 이유로 예측을 인위적으로 나쁘게 만들지 않습니다.
